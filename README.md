# Агу — синтез звуков и детских голосов

Next.js-приложение, которое синтезирует детские голоса, звуки игрушек и игровые эффекты.
Весь звук считается в браузере: без сервера, базы данных и авторизации. Любой результат можно скачать в WAV.

Интерфейс построен на [PathLogs UI](https://pathlogs-ui.vercel.app/docs): токены и темы из `@toimetdev/pathlogs-tokens`,
`AppShell`, `Button`, `Field`, `Badge`, `PageHint`, `ThemeToggle` из `@toimetdev/pathlogs-core`. Есть тёмная и светлая темы.
Раздел хранится в адресе (`/#toys`), поэтому ссылку на него можно отправить.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Что умеет

| Вкладка | Как работает |
| --- | --- |
| **Голос малыша** | «Слова» по умолчанию читает нейросеть Piper, затем голос превращается в детский под выбранный возраст. Смех, хихиканье, лепет, гуление, плач и песенку «ля-ля» делает формантный синтезатор (каскад Клатта): голосовые импульсы Розенберга с джиттером и придыханием плюс пять резонаторов речевого тракта ребёнка. Им же можно озвучить слова без интернета. Возраст: младенец / малыш / ребёнок. |
| **Текст → детский голос** | Нейросеть [Piper](https://github.com/rhasspy/piper) в браузере (onnxruntime-web) читает текст русским или английским голосом, затем голос превращается в детский. Модель (~60 МБ) скачивается с Hugging Face один раз и кешируется. Есть и быстрый режим на системных голосах (Web Speech API), но его нельзя сохранить в файл. |
| **Изменить голос** | Запись с микрофона или загрузка файла → детский голос. |
| **Игрушки** | Ксилофон, музыкальная шкатулка, колокольчик, погремушка, пищалка, пузырьки, свисток, барабан. |
| **Звуковые эффекты** | Порт генератора [sfxr](https://www.drpetter.se/project_sfxr.html): монетки, прыжки, бонусы, лазеры, взрывы, мутации и ручная настройка. |

Понравившиеся звуки можно складывать в «Мою коллекцию» внизу страницы. Она живёт в памяти до закрытия вкладки.

## Чтобы синтезированный голос не звучал как робот

`src/lib/audio/babySynth.ts`:

- **Русская фонетика.** Работает аканье и иканье (молоко+ → м[ə]л[а]ко́), мягкие согласные тянут форманты к «и», звонкие оглушаются на конце слова и перед глухими (хлеб → [хлеп]). Безударные гласные вдвое короче ударных.
- **Живой тон.** Контур интонации сглажен без изломов. К нему добавлен «флаттер» Клатта и медленный дрейф. Тон после глухих согласных начинается чуть выше, после звонких — ниже.
- **Живая громкость.** Внутри гласной громкость меняется и следует за высотой. Перед паузой голос затухает с выдохом.
- **Неровный ритм.** У каждого звука своя длительность с разбросом ±8%. Слова внутри фразы звучат слитно, без пауз.
- **Смех и хихиканье.** Слоги идут на выдохе: каждый резко начинается и затухает, высота скачет от слога к слогу. Часть слогов — просто выдох без голоса, последний тянется и сипнет, после серии слышен шумный вдох. Хихиканье часто начинается с «хм-хм» через нос, а вдох после него иногда с писком.
- **Мягкий источник.** Открытая фаза голосовой щели длиннее, полосы формант шире, верхние частоты приглушены, чтобы голос меньше «жужжал».

## Как взрослый голос становится детским

`src/lib/audio/childVoice.ts`:

1. **YIN** оценивает основной тон по кадрам 10 мс.
2. **TD-PSOLA** режет сигнал на зёрна по два периода вокруг голосовых импульсов и собирает их с новым шагом. Так меняется высота, а тембр остаётся прежним.
3. Каждое зерно дополнительно **сжимается во времени**: форманты поднимаются, как у короткого детского речевого тракта, а высота не меняется.
4. При повышении тона соседние импульсы **смешиваются**, а не повторяются, иначе появляется металлический призвук. Шумные согласные («с», «ш», «х») собираются из зёрен со случайным шагом, чтобы они не гудели.

Пресеты задают целевую высоту в герцах, а не множитель. Поэтому мужской и женский голоса приходят к одному результату. Для мужского исходника форманты сдвигаются сильнее.

## Структура

```
src/lib/audio/core.ts        WAV, воспроизведение, фильтры, реверберация
src/lib/audio/babySynth.ts   формантный синтез детского голоса
src/lib/audio/childVoice.ts  YIN + PSOLA, пресеты возраста
src/lib/audio/sfxr.ts        игровые звуки
src/lib/audio/toys.ts        звуки игрушек
src/lib/tts/piper.ts         нейросетевой TTS в браузере
src/components/              интерфейс
scripts/copy-wasm.mjs        копирует WASM-движки в public/wasm (запускается автоматически)
```
